# Créditos del mapa de Guatemala

`guatemala-departamentos.geojson`: límites de los 22 departamentos (nivel ADM1) de
[geoBoundaries](https://www.geoboundaries.org/) — versión simplificada de
`geoBoundaries-GTM-ADM1_simplified.geojson`, basada en datos de **OpenStreetMap**.

- Licencia: [Open Data Commons Open Database License 1.0 (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/).
- Atribución: © colaboradores de OpenStreetMap; geoBoundaries (Runfola et al., 2020).
- Cambios: se dejaron solo el nombre y el código ISO de cada departamento y las coordenadas se redondearon a
  3 decimales (unos 100 m) para reducir el tamaño. La app muestra la atribución debajo del mapa.
